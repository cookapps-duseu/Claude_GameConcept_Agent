# Claude GameConcept Agent

Claude Code와 대화하여 게임 컨셉안을 자동으로 생성하는 에이전트 파이프라인입니다.

## 개요

게임 아이디어를 대화로 구체화하면, AI가 레퍼런스 분석 → 재미 설계 → 컨셉 문서 작성 → UI 목업 생성까지 자동으로 수행합니다. 결과물은 HTML 파일로 저장됩니다.

## 사용 방법

**Claude Code**가 설치된 환경에서 이 프로젝트 폴더를 열고, 채팅창에 게임 컨셉 생성을 요청합니다.

```
게임 컨셉 만들어줘
```

```
로그라이트 모바일 게임 기획해줘
```

이후 Claude가 질문을 던지며 대화로 아이디어를 구체화합니다. 최종 확인 후 파이프라인이 자동 실행됩니다.

### 대화 흐름

| 단계 | 내용 |
|------|------|
| Phase A | 장르 / 타겟 유저 파악 |
| Phase B | 플랫폼, 그래픽, 레퍼런스 등 기본 항목 수집 |
| Phase C | 코어 루프 · 핵심 요소 심층 파악 |
| Phase D | 수집 항목 전체 확인 및 수정 |
| Phase E | 최종 확인 |
| Phase F | 파이프라인 자동 실행 |

### 파이프라인 단계

| 단계 | 내용 |
|------|------|
| Step 1 | 레퍼런스 게임 탐색 |
| Step 2+3 | 재미 요소 / 코어 루프 분석 |
| Step 4 | 분석 내용 요약 정리 |
| Step 5 | 게임 컨셉안 문서 작성 |
| Step 5.5 | 컨셉 품질 평가 |
| Step 6 | UI 목업 이미지(SVG) 생성 |
| Step 7 | HTML 파일 출력 |

각 주요 단계 완료 후 승인 게이트가 표시됩니다. `y`로 계속 진행하거나 `n`으로 중단할 수 있습니다.

## 결과물

`output/{날짜}_{게임이름}/` 폴더에 저장됩니다.

```
output/
└── 20260403_로그라이트 기반 단순 2D 모바일 게임/
    ├── concept.html       # 최종 게임 컨셉 문서
    ├── session.json       # 파이프라인 실행 상태
    └── pipeline.log       # 실행 로그
```

## 기획 구체화 (컨셉 생성 이후)

컨셉 생성 후 특정 영역(전투 시스템, 경제 구조, 레벨 디자인 등)을 추가로 구체화할 수 있습니다. 대화 완료 시 자동으로 결정 로그 MD 파일이 저장됩니다.
